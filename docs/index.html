💳 Single Source of Truth • 100% Offline

High-Performance Personal Finance on Native Android.

Engineered with Kotlin, Jetpack Compose, Material 3 Expressive, and Room SQLite. Features organic Canvas hero gradient animations, 8 Financial Hubs, Calendar Heatmap, 30-Day Activity Trends, and 10 dynamic palette styles with bundled Google Sans Flex.

⚡ Automated CI/CD Builds View Source Code on GitHub
🧠
Single Source of Truth
Every calculation across accounts, budgets, goals, debts, and insights is derived reactively from immutable Transaction records.
🌟
Animated Balance Hero
Native Compose Canvas organic background blobs, obscured balance privacy toggle, and dynamic >90% budget utilization indicator.
🗂️
8 Financial Hubs
Accounts, Budgets, Goals, Loans & Debts ledger, Recurring rules, Categories, Contacts, and an interactive Bill Splitter calculator.
📊
Calendar Heatmap & Trends
Daily spending intensity shading and high-performance 30-day cubic bezier sparkline curve rendered directly on Canvas.
🎨
10 Material 3 Palettes
Expressive, Tonal Spot, Vibrant, Rainbow, Fruit Salad, Spritz, Fidelity, Content, Monochrome, Neutral with pure AMOLED black mode.
🛡️
100% Offline & Private
Zero internet permissions declared. Offline-first local persistence via Room (SQLite) and bundled Google Sans Flex variable font.
Architectural Specifications
PlatformNative Android (100% Kotlin & Jetpack Compose BOM 2024.12.01)
Design LanguageMaterial 3 Expressive (32dp container radii, organic Canvas animations)
TypographyGoogle Sans Flex Variable Font (bundled offline in res/font/)
Local DatabaseRoom (SQLite) 2.6.1 with KSP
State ManagementKotlin Coroutines Flow with stateIn(WhileSubscribed(5000))
CI/CD PipelineGitHub Actions (android-ci.yml)
